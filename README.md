# GlyphForge

**GlyphForge** — браузерный редактор ASCII / glyph art, где изображение строится из букв, цифр и символов.

## Возможности

- ручное рисование символами по сетке;
- кисть и ластик с размером 1–9;
- квадратная и круглая форма кисти;
- кисть **Осветлить** — переводит символы к более светлой части шкалы плотности;
- кисть **Тень** — переводит символы к более плотной/тёмной части шкалы;
- линия, рамка и заливка;
- пользовательская шкала плотности символов;
- загрузка изображения как подложки;
- конвертация Image → ASCII;
- опциональное сохранение цветов исходного изображения;
- Undo / Redo;
- импорт и экспорт TXT;
- экспорт PNG;
- локальное автосохранение проекта;
- CRT-интерфейс со scanlines и свечением;
- темы **Ночь / День**;
- включаемый эффект «рыбьего глаза» с настройкой силы;
- настройки интерфейса сохраняются в `localStorage`.

## Свет и тень

Шкала плотности задаётся слева направо от тёмного к светлому, например:

```text
@%#*+=-:. 
```

Кисть **Осветлить** двигает текущий символ вправо, а **Тень** — влево.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| Q | Кисть |
| W | Ластик |
| E | Осветлить |
| R | Тень |
| T | Линия |
| Y | Рамка |
| U | Заливка |
| [ / ] | Уменьшить / увеличить кисть |
| Ctrl+Z | Отмена |
| Ctrl+Y | Вернуть |

## Запуск

Проект полностью статический. Достаточно открыть `index.html` в браузере или разместить репозиторий через GitHub Pages.

CRT-эффекты относятся только к интерфейсу редактора и не попадают в обычный PNG/TXT экспорт.
