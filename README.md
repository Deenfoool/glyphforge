# GlyphForge

Локальный веб-редактор ASCII / glyph art без сервера и зависимостей.

## Возможности

- рисование символами по сетке;
- карандаш, ластик, линия, рамка, заливка;
- собственный набор символов;
- цвет символов и фона;
- загрузка изображения как подложки для ручной обводки;
- автоматическая конвертация изображения в ASCII;
- импорт/экспорт TXT;
- экспорт PNG без сетки и подложки;
- копирование ASCII-арта в буфер обмена;
- undo/redo;
- локальное автосохранение через `localStorage`;
- полностью статический проект — подходит для GitHub Pages.

## Запуск

Можно просто открыть `index.html` в браузере.

Для локального сервера:

```bash
python3 -m http.server 8080
```

После этого открыть `http://localhost:8080`.

## GitHub Pages

Загрузите содержимое проекта в репозиторий и включите Pages из ветки `main`, корень `/`.
